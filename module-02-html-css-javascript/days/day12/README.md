# Habesha Eatery Website

This is a small 2-page website I built for a fictional restaurant in Bole, Addis Ababa for my Day 12 assignment.

## How to Open the Site

1. Download or clone this repository.
2. Double click `index.html` or `contact.html` to open them in your browser.

## Accessibility Features I Included

- **Semantic HTML:** I used real HTML tags like `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>` instead of just using `<div>` everywhere.
- **Headings:** I made sure each page has only one `<h1>` title, with `<h2>` tags for sub-headings.
- **Form Labels:** Every input field has a matching `<label for="">` so screen readers know what each field is for.
- **Tables:** I added `<caption>` titles to both tables and used `scope="col"` and `scope="row"` headers so the menu and opening hours are easy to read.
- **Media Descriptions:** The image has an `alt` tag describing the doro wat, and the Google Map iframe has a `title` attribute.
- **Keyboard Friendly:** You can tab through all the links, form fields, and submit buttons using just your keyboard.
